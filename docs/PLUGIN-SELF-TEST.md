## 1. 自动验收（推荐先跑这个）

```bash
npm run test:plugin-acceptance
```

它会用**真实 Chrome + 真实扩展 + 本地 fixture 招聘页**跑 10 项，约 1 分钟：

```
✔ 配对码获批 / 扩展已绑定
✔ 点击「采集当前页」→ 已自动入账（xx ms）
✔ 服务端生成业务记录 application_id=app_xxx
✔ status=pending, has_applied=0
✔ jd_text=119 字 / 8 段 / 含任职要求
✔ 前端可见（无需刷新）
✔ 重复采集只有一条
✔ 命中学习模板后重载页面不报错、仍识别
```

- 全绿退出码 0；任何一条失败退出码非 0，不会“假装通过”。
- 明细 JSON：`.tmp/plugin-acceptance-report.json`。

> 它测的是**稳定回归**（本地 fixture），不证明真实招聘网站的当前兼容性。

## 2. 真 Chrome 手动走一遍（验「授权即采 + 自动入账」）

### 2.1 加载扩展

1. 打开 `chrome://extensions`，右上角开「开发者模式」；
2. 「加载已解压的扩展程序」→ 选：
   ```
   /Users/mingenlin/Desktop/opencode project/帮你理/extension
   ```
3. 如果以前装过旧版（比如 `Desktop/.../帮你理/extension` 的旧副本），**先移除旧的再加载**，否则两个版本会抢同一个页面。

### 2.2 连后台 + 配对

1. 点扩展图标 → 后台地址填 `http://127.0.0.1:4311` → 保存；
2. 点「检测本机服务」应显示 `✅ http://127.0.0.1:4311`；
3. 点「开始配对（显示配对码）」→ 网页 <http://127.0.0.1:4311> 登录后进「设置 → 浏览器插件」输入配对码 → 点「我已确认，检查绑定」→ 显示已绑定。

登录验证码：outbox 模式不发邮件，终端读：

```bash
node --env-file=/Users/mingenlin/tounar-acceptance/20261025-060103/acceptance.env \
     server/scripts/latest-otp.js
```

### 2.3 授权当前页 → 立即采集

1. 浏览器打开一个真实岗位详情页，例如：
   `https://careers.tencent.com/jobdesc.html?postId=2099730961662128128`
2. 点扩展图标 → 「**将本站设为招聘网站并授权**」→ Chrome 弹权限 → 允许；
3. **不要刷新页面**。popup 里应该依次出现：
   `已授权 … 正在识别当前页…` → `已自动入账（xx ms）：<岗位名>`
4. 如果显示「这一页没有识别到岗位」，说明该页没有可识别岗位（首页/列表/登录页），换一个详情页。

### 2.4 到台账核对

1. 打开 <http://127.0.0.1:4311> → 点「看过没投」（未投递）；
2. 应该能看到刚才那个岗位，状态「待投递」；
3. 点开详情 → 应有「**JD 全文**」区块（不是 80 字摘要），且保留换行/分条；
4. 回到同一个岗位页再点一次「采集当前页」→ 台账里**仍然只有一条**。

### 2.5 自动浏览采集（不点按钮）

在已授权站点打开另一个岗位详情，**停留 3 秒以上**、不点任何按钮：
应该自动出现在「看过没投」。这条走的是原有 `job_viewed`（可见停留）路径，和「显式采集」是两个事件。

## 4. 看到这些说明有问题

| 现象 | 可能原因 |
|---|---|
| popup 显示「连不上 http://127.0.0.1:4311」 | 后台没起；`npm run local:acceptance` |
| 点授权后没有任何状态变化 | 当前 tab 不是 http(s) 页面；或 Chrome 没弹权限（已被旧版本占用） |
| 显示「已连接页面，但没有识别到岗位」 | 该页不是详情页；或站点改版导致识别不到（把 URL 发我） |
| 显示「服务端拒绝：插件不允许提交该事件类型」 | 后台跑的是旧代码，重启 `npm run local:stop && npm run local:acceptance` |
| 台账里没有「JD 全文」 | 该页只采到摘要（列表/侧栏），或站点没有职责区块 |
| 同岗位出现两条 | 站点给了不同的岗位 ID/URL，属于“同名不同 ID”，需要看具体页面 |

## 5. 这套自测覆盖不到什么（别当成全绿）

- **列表页采集**：还没实现，只能逐个详情采。
- **真实站点上的端到端**：自动验收用的是本地 fixture；真实站点目前只验证到“能识别字段”，没验证“入账 + 前端可见”。
- **学习模板复用**：只验证了“命中模板不崩”，没验证“A 岗学会、B 岗复用、改版重学”。
- **OPPO / 快手 / 拼多多 / BOSS**：未完成（快手要点击抽屉，BOSS 要登录态）。
- **性能 P50/P95**：只测了本地识别耗时（5–28ms），全链路时延没采样。
