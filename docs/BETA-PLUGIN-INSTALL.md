# 插件安装指引（Chrome，手动加载）

本轮不通过应用商店，不承诺网页点击自动安装。

1. 在帮你理页面点击「下载插件」，或使用页面上的 ZIP 链接。下载文件名：`bangnili-extension-0.2.2.zip`。
2. 解压到固定文件夹，例如 `文档/帮你理插件/`。解压后应直接看到 `bangnili-extension/manifest.json`；安装后不要删除或移动该文件夹。
3. Chrome 地址栏打开 `chrome://extensions`。
4. 打开右上角「开发者模式」。
5. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的 `bangnili-extension` 目录（不要选 ZIP 本身，也不要选上一级目录）。
6. 打开插件弹窗，确认后台地址为 `https://bangnili.app.workbuddy.host/?sharecode=…`，点击「保存并授权连接」。
7. 在网页「数据与授权 → 插件绑定」中输入插件显示的配对码，完成绑定。

- 浏览器支持：Chrome 为优先验收目标；其他浏览器未实际验证，不标注支持。
- 平台分享码用于打开托管网页；应用邀请码用于首次激活账号；插件配对码用于绑定当前账号，三者不要混用。
- 插件不会预置任何人的绑定状态或设备令牌。
