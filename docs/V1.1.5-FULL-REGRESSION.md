## 一、回归前置环境与门禁检查

### 1.1 版本与分支隔离检查

```bash
git branch --show-current          # 应为 tounar-1.1.5（基于 tounar-1.1.4）
git rev-parse v1.0.0               # 确认与冻结提交 a77d740 完全一致
node -e "console.log(require('./package.json').version)"  # 应为 1.1.5
```

- 检查 `git status` 无 `.env`、SQLite 数据库文件、真实个人邮件或 `.tmp/` 临时截图被误纳入暂存区。

### 1.2 启动本地隔离验收服务

```bash
DIR=./.tmp/v1.1.5-regression
mkdir -p "$DIR"
PORT=4328 DATA_DIR="$DIR" DB_PATH="$DIR/tounar.sqlite" npm run start
```

- 健康检查：`curl -s http://127.0.0.1:4328/api/health` 必须返回 `ok: true` 且 `version: "1.1.5"`。
- 获取隔离库登录验证码：

```bash
DATA_DIR="$DIR" DB_PATH="$DIR/tounar.sqlite" npm run otp:latest
```
