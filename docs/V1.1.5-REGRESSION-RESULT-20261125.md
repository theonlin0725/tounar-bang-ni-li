## 一、已实施修改

### 1. AI 助手统一为半屏抽屉

- `web/assets/js/app.js`
  - `?panel=assistant` 仅作为深链兼容：底层固定挂载「投递台账」，右侧打开唯一半屏抽屉，清理 URL 中的 `panel/app/resume/onboarding`。
  - 新增 `tounar:open-assistant` 事件、`window.__tounarOpenAssistant()`、`toggleAssistantDrawer()`；底部入口与抽屉打开态同步高亮。
  - 抽屉关闭不销毁已挂载对话；同上下文再次打开直接聚焦输入框。
  - 模态框打开时 Esc 优先关闭模态框，不再连带收起抽屉。
- `web/assets/js/views/assistant.js`
  - `renderAssistant()` 首行清空容器，加载态移入对话滚动区内部。
- `web/assets/app.css`
  - 桌面默认 `min(50vw, 760px)`，加宽 `min(72vw, 1080px)`，移动端全屏；完整 Flex 列布局，输入框不再被裁切。
  - 桌面隐藏悬浮球与抽屉遮罩；移动端保留遮罩。
- `career.js` / `resume-rewrite.js` / `detail.js` / `plugin-access.js`
  - 5 处旧整页跳转改为原地触发抽屉；保留 `href` 供右键新标签打开。

### 2. 左侧导航入口迁移

- 「分析」分组仅保留「匹配分析」「简历库」。
- 账号区上方新增独立底部入口 **`AI 投递助理`**，保留 `data-test="nav-assistant"`。
- 账号区与入口整体置于 `.tn-sidebar-bottom`，不再与 `margin-top:auto` 冲突。

### 3. 新手 4 步引导完成态校验

- `web/assets/js/views/onboarding.js`
  - 新存储键 `tounar.onboarding.v115.`，忽略 v1.1.4 误写的 `done: true`。
  - 完成条件为 `paired && jobs > 0 && mailBound`，并按真实状态推进步骤。
  - 「稍后再说 / 稍后同步」只隐藏当前挂载实例，不写永久标记；切回台账或刷新会重新出现。
  - 仅在完成态点击「开始使用」时写入 `{ completed: true, version: '1.1.5' }`。
  - 增加 4 步进度指示（`1/4`–`4/4`）。
- `web/assets/js/views/plugin-access.js`
  - 台账存在 `#tn-onboarding` 宿主时不再叠出旧版插件安装弹窗。
  - 画像引导改为触发 `tounar:open-assistant`，不再整页跳转。

### 4. 回归中发现的基线问题

- `server/src/cloud/persistence.js`
  - 云快照上传进行中，`pending` 曾短暂误报为 `false`；新增 `uploading` 标记，`pending = dirty || uploading`。
  - 该问题在 `tounar-1.1.4` 基线同样存在，修复后 `npm test` 由 265/267 提升至 267/267。

### 5. 静态资源版本

- `web/index.html` 与所有前端模块 query 统一刷新为 `?v=20261125-1`。
