## 三、分项详细改造方案

### 任务 1：AI 助手统一为「半屏可交互抽屉」，彻底消除全屏冲突

#### 1.1 彻底取消独立全屏 `panel=assistant` 主页面（保留深链兼容）
- **修改文件**：`web/assets/js/app.js`
- **具体逻辑**：
  1. 在 `enterApp(panel)` 中，如果 `activePanel === 'assistant'`：
     - **不再**在 `#tn-main` 中调用 `renderAssistant(main, ...)`；
     - `#tn-main` 正常挂载默认底层工作区 **`renderLedger(main, { gen, initialView: 'applied' })`**（投递台账），保证主工作区始终可用；
     - 用 `history.replaceState` 将 URL 中的 `panel=assistant` 清理掉（避免刷新后停留在废弃的 panel），同时把原始查询参数 `applicationId`、`resume`、`onboarding` 透传给 `openAssistantDrawer({ applicationId, resumeId, onboarding })`，在底层台账挂载完成后自动展开半屏抽屉。
  2. 暴露全局统一的抽屉唤起方法（供各业务页零刷新呼出）：
     - 在 `buildShell` 中监听自定义事件 `window.addEventListener('tounar:open-assistant', (e) => openAssistantDrawer(e.detail || {}))`，并在 `window.__tounarOpenAssistant`（或 `app.js` export `openAssistant(opts)`）提供显式调用入口；
     - 同步支持 `toggleAssistantDrawer()`：抽屉已打开时再次点击底部入口则收起，未打开时则展开。
  3. 改造所有旧 `/?panel=assistant` 业务入口，改为**不刷新页面直接展开半屏抽屉**（保留 `href` 兜底防止右键新标签打开失效）：
     - `web/assets/js/views/career.js` L296（`profile-ai`：「用 AI 助手梳理」）→ `e.preventDefault(); openAssistant({ onboarding: 'profile' })`；
     - `web/assets/js/views/career.js` L629（`match-ask-assistant`）→ `e.preventDefault(); openAssistant({ applicationId })`；
     - `web/assets/js/views/resume-rewrite.js` L55（`rewrite-profile-ai`）→ `e.preventDefault(); openAssistant({ onboarding: 'profile' })`；
     - `web/assets/js/views/detail.js` L168（岗位详情页「问 AI 助手」）→ `e.preventDefault(); openAssistant({ applicationId: id })`；
     - `web/assets/js/views/plugin-access.js` L138–139（`maybeProfileOnboarding`）→ 不再 `location.assign('/?panel=assistant&onboarding=profile')`，改为触发 `tounar:open-assistant`（`{ onboarding: 'profile' }`）。

#### 1.2 修复抽屉 DOM 挂载与 Flex 高度布局，确保半屏完整可对话、可交互

  2. **升级为半屏抽屉尺寸（桌面端默认 50vw）**：

  3. **保留全部既有 AI 助手功能与上下文状态**：

  4. **抽屉收起不销毁进行中对话**：

### 任务 3：新手 4 步引导完成态校验与「稍后再说」回页重现机制

- **修改文件**：`web/assets/js/views/onboarding.js`、`web/assets/js/views/plugin-access.js`、`web/assets/js/app.js`
- **核心规则**：
  > 只有当用户真正完成全部 **4 步**（1. 插件检测通过 → 2. 插件已安装并授权 → 3. 至少成功抓取/入库 1 条岗位 → 4. 已完成邮箱授权与同步配置），才视为引导结束；在 4 步未全部完成前，点击「稍后再说」仅让引导卡片在**当前这一次停留**暂时隐藏，**一旦用户切回投递台账界面或刷新/重新进入页面，引导弹窗必须再次自动出现**，并停在当前尚未完成的那一步。

- **具体实现设计**：
  1. **明确 4 步完成态判定函数 `evaluateCompletion({ paired, jobs, mailBound })`**：
     - Step 1：自动检测插件（瞬态过渡步）；
     - Step 2 未完成条件：`!paired`（插件未安装或未授权）；
     - Step 3 未完成条件：`paired && jobs === 0`（尚未完成首次岗位抓取）；
     - Step 4 未完成条件：`paired && jobs > 0 && !mailBound`（尚未完成邮箱授权与同步）；
     - **全部完成条件（Step 5）**：`paired && jobs > 0 && mailBound`（四步全部达标）。
     - *补充校验*：在卡片头部增加清晰的 4 步进度指示（如 `1/4`、`2/4`、`3/4`、`4/4` 进度条或步骤点），让用户一眼知道还差哪几步才算全部完成。
  2. **彻底分离「暂隐（稍后再说）」与「永久完成（4 步全过）」**：
     - **`dismissTemporarily()`**（绑定到右上角 `稍后再说` 以及 Step 4 的 `稍后同步`）：
       - **严禁写入** `done: true` 到 `localStorage`；
       - 仅设置本次挂载实例的 `disposed = true`，停止轮询 `clearInterval(poll)`，清空 `host` DOM，并在本次页面停留期间设置一个内存标记（非 `localStorage`）防止同页立刻重复弹出；
       - 当用户从其他页面（匹配分析、简历库、设置等）切回「投递台账」（`ledger`），或刷新页面、重新登录时，`mountOnboardingGuide()` 重新挂载并实时请求 `/api/v1/me`、`/api/v1/ledger` 与 `probeExtension()`，只要 `!(paired && jobs > 0 && mailBound)`，引导卡片就会**自动重新出现**！
     - **`markAllCompleted()`**（**仅在** `paired && jobs > 0 && mailBound` 全部为 `true`，进入 Step 5 完成态并点击「开始使用」时触发）：
       - 才向 `localStorage` 写入 `{ completed: true, version: '1.1.5', completed_at: new Date().toISOString() }`；
       - 同时升级存储 key 前缀为 `tounar.onboarding.v115.`（或读取旧 key 时忽略旧 `v114` 里由「稍后再说」误写的 `done: true`，只认新字段 `completed === true` 且经实际状态核验），确保之前误点过「稍后再说」的测试账号升级到 `1.1.5` 后也能立刻恢复正常引导！
  3. **与旧版 `plugin-access.js` 弹窗防冲突**：
     - `web/assets/js/views/plugin-access.js` 的 `promptPluginConnection({ automatic: true })`：在「投递台账」页面（存在 `#tn-onboarding` 宿主容器时），统一交由 `onboarding.js` 承担 4 步引导，不再叠出旧版重复弹窗；仅在用户主动点击「设置 → 插件连接/网站授权」时打开 `confirmPluginConnection` / `openSiteManager`。

## 五、开发完成自检标准（进入全量回归前必过）

1. 打开 `/?panel=assistant` 或 `/?panel=assistant&onboarding=profile`：页面底层显示「投递台账」，右侧滑出**单一半屏 AI 抽屉**，**不再出现**双实例，顶部**不再出现**卡死的「正在打开 AI 助手…」，底部上下文栏与输入框完整可见且可直接发消息获得流式回复。
2. 左侧导航栏「分析」下仅剩「匹配分析」「简历库」；最底部账号区上方显示 **`AI 投递助理`**，点击可丝滑切换抽屉开关。
3. 使用未完成 4 步配置的账号进入「投递台账」→ 弹出新手引导 → 点击「稍后再说」弹窗消失 → 切到「匹配分析」再切回「投递台账」（或刷新页面）→ **引导弹窗再次出现并停在当前未完成步骤**；直到完成全部 4 步并进入完成态点击「开始使用」后，刷新与切页不再弹出。
