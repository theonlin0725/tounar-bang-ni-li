## 一、实现范围与红线检查

1. **多语言文案与状态解析**（`web/assets/js/views/home-i18n.js`）
   - 语言解析优先级：`URL ?lang=en|zh` > `localStorage.getItem('tounar.home.lang')` > 默认 `'zh'`。
   - 完整保留既有中文文案逐字不变；新增原生化英文短句与祈使句文案（含文档标题、Meta 描述、顶栏导航、Hero 3 步指引、宣言带、四大功能区块、截图路径栏与独立 DOM 悬浮标注、底部 Start 与信任条）。
2. **原地切换与元数据清理**（`web/assets/js/views/home.js`）
   - 在 `.tn-home-nav-actions` 最左侧增加紧凑胶囊分段切换器 `中 | EN`（`data-test="home-lang-switch"`、`home-lang-zh`、`home-lang-en`，`role="group"`，`aria-pressed` + `.is-active`）。
   - 采用节点引用原地更新，切换语言时保留 `window.scrollY`、当前激活的 ScrollSpy Tab、已渐显区块的 `.is-visible` 状态、「看过没投 / 已投递」悬浮切换状态与邮件轮播进度，并在 `requestAnimationFrame` 与 `document.fonts.ready` 后重算 `navPill` 宽度与位置。
   - 在英文模式下原地更新 `pluginDownloadLink(...)` 返回 `<a>` 的英文 `label` 与 `title`，未修改 `plugin-help.js`。
   - `renderHome()` 返回的 `cleanup()` 自动恢复 `document.documentElement.lang = 'zh-CN'`、默认中文 `document.title` 与 `<meta name="description">`。
3. **本地托管 Nunito 字体与严格 CSP 兼容**（`web/assets/fonts/nunito-latin-var.woff2`、`web/assets/home.css`）
   - 托管开源 OFL 协议 Nunito Latin Variable WOFF2（`39,152` 字节，覆盖字重 `400..800`，零外网请求），通过同源 `@font-face` 引入（`font-display: swap`）。
