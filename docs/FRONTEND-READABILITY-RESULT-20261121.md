# 前端可读性改版交付记录（2026-11-21）

基线：`e7bc638`。本单候选提交见当前 `HEAD`。

## 1. 简历库

### 界面

- 删除 `1. 简历` 序号、页首长说明、正常状态模型服务横条和“返回台账”按钮；侧栏仍可回台账。
- 首屏顺序改为：上传/粘贴操作 → 当前版本 → 画像摘要 → 其他版本。
- 文件格式与 5 MB 限制放到文件选择处；文本输入框只在点「粘贴文本」后出现。
- 当前版本显示文件名、时间、状态、版本 ID；其他版本行显示独立 ID、时间、状态和操作。
- 画像默认只显示「主要技能」「经历 / 项目」两组摘要：
  - 每组最多显示两个已有名称/角色，再显示剩余条数。
  - 组内明细和原文证据默认收起，展开后才显示；空画像给出下一步。
  - 行业经验、突出优势、关键限制收进「更多画像」。
  - 经历组使用中性「经历 / 项目」标签，不把学历误写成工作经验。

### 版本与异步状态

- 文件控件支持多选，按选择顺序逐份上传；每份独立显示成功/失败，失败项可单独重试。
- 同名文件保留独立版本 ID；上传后默认最近创建版本为当前。
- 版本列表使用稳定游标和「加载更多」，20 份之后的历史仍能找回。
- 预览调用 `GET /api/v1/resumes/:id`，显示完整文本，不改变当前版本。
- 「设为当前」调用独立 `POST /api/v1/resumes/:id/current`：
  - 事务内验证账号归属，复用 `is_current` 唯一索引；
  - 重复点击幂等；
  - 不修改简历内容 `updated_at`。
- 当前、预览、分析中状态按 ID 分开；异步分析结果按 ID 合并，不再直接替换页面当前版本。
- 「修正文本」读取完整原文后编辑并保存，不使用 800 字预览回填。
- 旧报告仍使用生成时简历快照；新匹配/推荐明确显示当前简历文件名和版本时间。

### 后端接口

```text
GET  /api/v1/resumes?limit=20&cursor=...
POST /api/v1/resumes/:id/current
```

`GET /api/v1/resumes` 保持原 `data` 数组格式，额外返回 `page: { has_more, next_cursor }`。

## 2. 设置

- 已登录侧栏五项合并为一个「设置」：
  - `/?panel=settings` 进入提醒设置。
  - `/?panel=settings&tab=reminder|data|install|mail-admin`。
  - 旧 `/?panel=mail-admin` 进入对应管理页签。
  - `plugin-connect`、`plugin-sites` 进入数据与授权页签并继续原配对/授权动作。
- 设置页与台账内「去处理」复用同一个 `buildSettings` 主体和原表单、权限、失败恢复逻辑。
- 页签：提醒设置、数据与授权、安装指引、邮件测试与模板（仅管理员）。
- 安装指引内直接提供当前包下载按钮和版本标签；登录页、设置页、设备升级提示共用 `PLUGIN_VERSION` 常量。
- 页面 URL 页签、刷新、前进后退、窄屏页签换行均有覆盖。
- 普通用户不显示邮件管理页签；直接请求页签显示「仅管理员可访问」，后端 API 仍独立鉴权。

## 3. 单岗匹配、历史、优势与差距

- 选岗区删除两段划线说明和常驻状态行；副标题统一为“帮你选择合适的岗位”。
- 搜索框和岗位选择器同排，窄屏上下排列。
- 当前岗位行显示公司/岗位、城市、原岗位和「查看历史报告」；历史列表点击后才展开。
- 历史项显示日期、所用简历、结论或失败状态；历史查询在 SQL 中先按岗位过滤再排序分页。
- 报告头显示生成时岗位；当前台账名称变化时并列显示当前名称；报告 ID、`match-v2` 版本和生成时间收在「报告信息」。
- 首屏结论卡、总体建议、硬门槛阻断、六维折叠和五项行动沿用上一轮，并继续不显示百分比/雷达。
- `优势与差距` 改为四个可展开组：技能、工具、经历、项目；其他条件进入「其他岗位条件」。
  - 组头显示优势/明确差距/待补证计数；打开后分三组逐条显示。
  - 支持「维度依据」标识、回到对应六维、补充经历/纠错。
  - 同一结论重复只计一次，并合并证据入口。
  - 旧快照无主题字段时保守归类并显示旧报告提示；不声称引文精确配到某一条。
- 服务端按单条事项补充 `topic`、`status_group`、`evidence_scope`：
  - 未提及、未发现、暂无、用户偏好不明 → 待补证；
  - 明确年限/条件冲突 → 明确差距；
  - 技能、工具、经历、项目分别归类。

## 4. 未投递岗位推荐

- 标题改为「未投递岗位推荐」，删除序号。
- 每个岗位三块卡片：推荐理由（中性）、匹配优势（淡绿）、主要缺口（浅琥珀）；桌面三列、窄屏单列。
- 每块先显示两条，超过两条出现「展开其余 N 条」。
- 空数组显示「暂无已核实内容」。
- 下一步行动和岗位链接放到卡片底部；保留排名、相对匹配、地点、JD 不足列表和全量候选扫描。

## 5. 岗位对比下线

- 台账移除选择列、表头全选、跨页选中状态、对比条和对比样式；原筛选、状态编辑、补录、归档、邮件处理独立保留。
- 匹配页移除 `selectedIds`、对比区、`runCompare` 和自动运行分支。
- 旧 `?panel=career&apps=...&autorun=compare` 会在路由层清除参数，安全落到单岗选岗页，模型调用为零。
- `POST /api/v1/ai/compare` 返回 `410 AI_COMPARE_RETIRED`，不调用模型、不写报告。
- 历史 compare 报告读取接口仍保留；不迁移删除旧记录。
