## 1. 两个 Bug 的根因与修复

| Bug | 根因 | 修复 |
| --- | --- | --- |
| 没有全选 | 弹窗只渲染单个网站/域名复选框，首次引导默认折叠；没有全选条与一键授权入口 | 新增固定全选条（三态复选框 + `已选 X / Y` + 清空选择）；新增「一键授权全部」；首次引导默认展开完整列表 |
| 点击网站自动往上跳 | 勾选网站组时调用 `renderList()`，`clear(list)` 让滚动高度归零，`scrollTop` 被重置为 0；`render()` 重绘也丢失滚动位置和 `<details open>` | 勾选改为局部原地更新；重绘前后保存/恢复 `scrollTop` 和已展开的「查看域名」；授权完成立即刷新并补一次 350ms 校验，不清空当前筛选与滚动位置 |

## 2. 交互行为

- **全选当前列表**：只作用于当前搜索/筛选结果中的未授权网站；全选、部分选中（`indeterminate`）、未选三态实时同步。
- **一键授权全部**：汇总全部未授权网站的 origins，一次权限确认完成批量授权。
- **授权选中网站（X）**：保留原逐个勾选路径，按钮实时带已选数量。
- **滚动与展开态**：勾选、取消、搜索、Tab 切换、授权后刷新均保留列表滚动位置和已展开域名。
- **授权完成即时刷新**：`complete` 事件后立即拉取一次状态，300ms 后补一次校验；顶部已授权数、行内状态、复选框禁用态和选择集合同步更新。
- **清理选择**：新增 `清空选择`；已授权 Tab 下同样支持全选/清空待撤销网站。
