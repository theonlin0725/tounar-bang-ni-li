客户端 `unpair({cleanup=true})` 默认清空队列；`pollPairing()` 在设备 ID 改变时也会清空队列。因此不应在当前有待上传事件时直接建议“解除后重新绑定”。这段逻辑为原有实现，不是本次邮件改动新增。
