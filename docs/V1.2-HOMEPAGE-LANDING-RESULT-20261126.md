## 2. 路由分流

| 访问场景 | 会话 | 结果 |
| --- | --- | --- |
| `/` | 未登录 | 官网首页（`data-test=home-page`） |
| `/` | 已登录 | 工作台，不闪现官网 |
| `/?view=home` | 任意 | 官网预览；已登录时主按钮为「进入工作台」 |
| `/?view=login` | 未登录 | 现有 OTP 登录页，含「← 返回官网首页」 |
| `/?view=login` | 已登录 | 直接进入工作台并移除 `view` 参数 |
| `/?panel=reviews` 等深链 | 未登录 | 先登录并保留 URL，登录后恢复面板（行为不变） |
| `/?panel=ledger&view=viewed` | 已登录 | 台账「看过没投」视图（`view=viewed` 不会被登录/官网分流删除） |
| `/r/<token>` | 任意 | 邮件落地页（行为不变） |
| 退出登录 / 会话失效 | 已登出 | `/?view=login`，保留退出或过期提示 |

## 3. 交互实现

- **吸顶顶栏**：滚动超过 24px 加 `.is-scrolled`（毛玻璃 + 阴影）；桌面胶囊 Tab 使用滑动指示器，窄屏切换为横向可滚动 Tab 条。
- **ScrollSpy**：`IntersectionObserver` 同步当前功能区块与 Tab 高亮；点击 Tab 平滑滚动并更新 hash；所有功能区块设置 `scroll-margin-top`。
- **首屏入场**：`requestAnimationFrame` 后加 `.is-ready`，标题 / 副文案 / CTA / 截图错峰淡入。
- **滚动渐显**：文案列、截图外框、悬浮标注三段错峰；触发一次后 `unobserve`。
- **邮件轮播**：`#mail` 可见时每 2.4s 在「一面 → 二面 → 三面」间柔和切换，离开视口或悬停/聚焦时暂停。
- **微视差**：截图外框悬停时内部截图轻放大、外框阴影加深、独立 DOM 悬浮标注反向轻浮。
- **减动效**：`prefers-reduced-motion: reduce` 下关闭位移、缩放、轮播与平滑跳转。
- **视图清理**：`renderHome()` 返回清理函数，`app.js` 在登录页 / 工作台 / 落地页切换时断开所有 observer、定时器与事件监听。

## 4. 截图采集与脱敏

- 使用 `startTestServer` 启动隔离 `DATA_DIR`，只写入虚构公司（星河科技、明镜数科、云帆智造、远山网络、清风互动、深蓝云图）与 `alex@example.com`。
- Playwright `deviceScaleFactor: 2`，1280×800（16:10）桌面视口，最终转 1920px 宽 WebP（单张 47–96KB）。
- 五张图分别覆盖：投递台账、插件待确认线索、简历改写审阅、邮件状态时间线、AI 助手待确认操作卡。
- 图片缺失时前端自动回退为纯 CSS 结构预览卡，不出现破图图标；Hero 图 `fetchpriority=high` 非懒加载，其余懒加载并标注宽高。

## 6. 已知边界

- 官网截图是隔离演示库的真实界面，但为了让画面聚焦，采集脚本会临时隐藏侧栏、字段明细表和助手输入区；产品本身没有这些隐藏逻辑。
- 尚未在真实 Safari / Firefox 与真机做全量视觉验收；已覆盖 Chromium 1280/1440 桌面与 390px 移动视口，横向溢出为 0。
- 现有分支功能不改动；合并时唯一需要保留的冲突点是 `app.js` 的 `view` 分流与 `enterApp()` 中「只删除 `view=login|home`、不删除 `view=viewed|archived`」的保护。
