# 插件连接与招聘网站授权（本地待审核）

分支：`yuyiran/plugin-pairing-permissions`。基于 `codex/beta4-local-review-20261103` 的 `06906de`。

## 改动范围

1. v0.2.4 在打开网页并登录后自动检测当前浏览器的插件与账号绑定状态；未连接时主动弹窗，点击「确认连接」才发起绑定，成功后直接进入网站授权。无需先打开插件栏。「暂不连接」在本次标签页访问中记住；未检测到插件时显示安装/更新和重新检测入口。保留原有服务器配对协议与有效期；页面不要求输入配对码，交换密钥和设备令牌不传到网页。
2. 「数据与授权」新增招聘网站授权卡片。首次预选字节跳动，但不自动申请浏览器权限；其他公司折叠，可搜索公司或域名，展开具体域名。管理弹窗支持查看、添加、单独及批量撤销。统计按公司分组，排除后台连接权限。权限保存在当前浏览器插件内，不表示其他设备已授权。

网页通过仅限当前后台来源的桥接与插件通信。网站授权/撤销在插件确认窗口再次展示具体范围；新增权限调用浏览器原生权限申请。未确认、拒绝或取消不会标为已授权。没有新增服务器接口，也没有修改采集、队列、邮件或台账业务逻辑。

## 本地体验

- 网站沿用当前本机服务。
- 在 Chrome 扩展管理中停用旧插件，加载本次新版解压目录；不要同时启用两份插件。
- 加载 v0.2.4 后回到网页刷新，登录后自动弹窗确认，无需先配置插件或点击插件栏。
- 打开网页「数据与授权」，尝试预选、展开更多、搜索、授权及撤销。
- 原生 Chrome 权限提示的允许/拒绝操作仍需人工验收；自动化验证了请求确认窗口、取消、来源校验与授权统计，不声称已验证真实招聘网站采集。

## v0.2.5 页内授权确认

「授权选中网站」和撤销操作改为当前页面上叠加的小确认框，不调用 chrome.windows.create、不打开新标签页。确认控件位于扩展自身的嵌入页面中，用户直接点击后调用权限 API；外层网页只接收该嵌入窗口、该请求 ID 的完成消息。Chrome 自身的权限提示仍由浏览器处理。

请求使用随机 ID、两分钟有效期，并绑定发起标签页、网页来源和当前后台。取消会关闭小框并保留原来的选择；成功后关闭小框并由实际权限状态更新列表。后台响应的 CSP 仅追加允许加载 chrome-extension 框架，以支持该界面。

验证：独立有界面 Chromium 中，12 项页内确认检查通过，包含真实 permissions.request 授权、remove 撤销、取消不授权、同页更新、窗口与标签页数量不变。测试使用临时账号及浏览器配置，没有更改用户的站点权限。另将现有插件管理用例迁移为嵌入确认框，保持配对与取消覆盖。

浏览器接口依据：[Chrome permissions API](https://developer.chrome.com/docs/extensions/reference/api/permissions)、[Web Accessible Resources](https://developer.chrome.com/docs/extensions/reference/manifest/web-accessible-resources)。本地包已更新为 0.2.5；升级插件并刷新网页后生效。
