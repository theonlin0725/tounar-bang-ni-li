# 帮你理（Tounar BangNiLi）

**把看过的岗位、该投的选择和投递后的进展，整理在一起。**

帮你理是一款面向求职者的**岗位记录、简历匹配与投递进度管理工具**，重点打通求职投递中和投递后的环节。通过浏览器插件、网页台账、AI 简历分析和邮件提醒，帮助你回答四个问题：

- **我看过哪些岗位，还没投哪些？**
- **结合我的简历，哪些岗位更值得投？**
- **已经投过的岗位，现在进展到哪一步？**
- **投递过去多久了，哪些需要回看和跟进？**

适合同时浏览、比较和投递多个岗位，希望减少手动记表、避免遗漏进展的求职者。

## 一个完整的投递闭环

**浏览岗位时自动记录 → AI 分析简历与岗位匹配度 → 实际投递后自动更新状态 → 邮件提醒与复盘回看**

例如：你浏览了几个感兴趣的岗位，插件把它们记入「看过未投」台账；上传简历后，通过 AI 对比选择优先投递的岗位；完成投递后，系统根据识别到的投递信号更新为「已投递」；后续收到笔试、面试等招聘进展，或到了该回看的时间，再通过台账和邮件提醒你跟进。

## 四项核心功能

### 1. 自动抓取岗位：看过的机会，先帮你记下来

安装并绑定浏览器插件后，在支持的招聘页面浏览岗位，插件会自动识别岗位信息，将看过但尚未投递的岗位记录到网页的「看过未投」台账。

你可以集中查看公司、岗位和原始链接，之后再比较和决定是否投递，减少来回翻找页面、手动复制信息的负担。采集范围取决于站点适配与页面信息，缺失内容可手动补充。

### 2. 简历分析与岗位匹配：帮助你判断该投哪些岗位

上传 PDF、DOCX 简历或粘贴简历文本后，接入的 AI 大模型会分析简历中的技能与经历，结合台账中的岗位要求提供匹配分析。

你可以选择多个岗位进行对比，查看匹配依据、优势与差距，也可以从尚未投递的岗位中获取优先考虑的建议，让投递选择更有依据。分析需要配置可用的 AI 服务，并依赖简历和岗位信息的完整程度。

### 3. 投递状态自动更新：从「看过未投」到「已投递」

积累岗位并实际完成投递后，系统根据插件识别到的投递行为和已授权邮箱中的招聘邮件，匹配对应岗位、更新台账。

例如，原本在「看过未投」中的岗位，识别到有效投递信号后会归入「已投递」；后续也可记录笔试、面试、录用或拒绝等进展。信息不足或存在歧义时进入「待确认」，由你核对；你也可以手动修正状态。

### 4. 邮件提醒与复盘：投完之后，继续帮你跟进

通过 **QQ 邮箱授权码**连接邮箱：IMAP 用于读取授权范围内的招聘邮件、识别进展，SMTP 用于发送提醒。

系统结合台账记录与提醒设置，告诉你哪些岗位有新进展、投递已过去多少天、哪些到了该回看的时间。通过邮件中的链接返回对应记录，回看岗位和进展，再决定是否继续跟进。

## 打开产品后，各个页面可以做什么？

| 页面 / 入口 | 你可以在这里做什么 |
| --- | --- |
| **岗位台账** | 集中查看「看过未投」与「已投递」岗位，搜索和筛选记录，查看累计投递、进行中、面试中等统计 |
| **岗位详情** | 查看岗位信息、原始岗位链接和进展记录，补充信息或修正状态 |
| **简历与 AI** | 上传和管理简历，分析简历画像，对比多个岗位，查看未投递岗位的匹配建议 |
| **待确认** | 核对无法直接判断的岗位线索或招聘进展，补充信息后确认入账，或忽略无关内容 |
| **提醒设置** | 设置进展通知、回看提醒的方式与周期 |
| **数据与授权** | 连接或断开 QQ 邮箱，管理插件设备与数据授权 |

## 如何开始使用

1. **登录网页并绑定插件**：安装浏览器插件，将插件与你的账号及服务绑定。
2. **照常浏览岗位**：在支持的招聘页面浏览岗位，回到台账查看「看过未投」记录。
3. **上传简历，比较岗位**：在「简历与 AI」中上传简历，选择岗位分析匹配度，确定优先投递的机会。
4. **完成实际投递**：在原招聘网站提交申请，系统识别到有效信号后更新台账；有歧义的记录在「待确认」中处理。
5. **连接邮箱并设置提醒**：配置 QQ 邮箱授权与发信服务，按自己的节奏接收进展和回看提醒。

## 当前版本与体验说明

当前为 **Beta 版本**，包含浏览器插件、网页台账、简历 AI 和邮件跟进能力。真实使用需要完成插件绑定、AI 服务和邮箱配置；招聘站点覆盖、模型分析效果与邮件送达情况，以对应环境的实际验证为准。

- 自动记录与状态更新依赖可识别的页面或邮件信号；未识别的内容可补录或确认。
- AI 提供岗位匹配和选择参考，最终投递决定由你作出。
- 本地开发默认使用 outbox 保存邮件；接收真实邮件提醒需要启用并配置 SMTP 发信。

## 本地运行与开发资料

本地运行需要 Node.js 24 或以上版本。

```bash
npm install
cp .env.example .env
# 按 .env.example 配置本地环境后启动
npm start
```

启动后打开 [本地网页](http://127.0.0.1:4310)。安装浏览器插件时，在 Chrome 扩展管理页开启开发者模式，选择「加载已解压的扩展程序」并加载仓库中的 `extension/` 目录。
